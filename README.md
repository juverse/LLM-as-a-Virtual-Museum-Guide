# LLM-as-a-Virtual-Museum-Guide
This project explores the integration of a Large Language Model (LLM) with Virtual Reality (VR) using Unity and C# to create an interactive, immersive, and personalized museum experience. A prototype digital assistant was developed to guide users through a virtual museum environment, offering contextual information and engaging in real-time conversational interaction.

The assistant utilizes OpenAI’s real-time API to process user input and generate dynamic, context-aware responses. This allows for natural, fluid dialogue between the user and the virtual guide within the VR setting.

The project documents the technical implementation of the prototype and presents a user study designed to evaluate its usability, interactivity, and overall effectiveness.
